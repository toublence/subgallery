# SubGallery App Store Storyboard (ko-KR Trial)

1. `01-separate`: 기본 사진 앱과 분리된 보관함을 먼저 보여준다.
2. `02-camera`: 앱 안에서 바로 촬영하고 목적을 선택하는 흐름을 보여준다.
3. `03-albums`: 여행 앨범처럼 목적별 도착 지점을 보여준다.
4. `04-batch`: 전체 선택과 여러 장 일괄 처리를 보여준다.
5. `05-retention`: 완료 대기와 오늘·7일·이후 정리 상태를 보여준다.
6. `06-search`: `제주` OCR 검색으로 사진 속 글자가 검색되는 것을 증명한다.
7. `07-private`: 실제 PIN 잠금화면으로 접근 보호를 보여준다.

모든 화면은 `-store-screenshot` 실행 인수로 만든 격리된 인메모리 데이터와 실제 Release 앱 UI를 사용한다.
